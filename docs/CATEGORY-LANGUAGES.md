# კატეგორიების ენები და ბორდოს აქცენტები

კატეგორიის ძირითადი სახელი აქამდე ყველა ენაზე უცვლელად გამოდიოდა.
ინტერფეისის ლექსიკონი მას საერთოდ არ ამუშავებდა; სორტირების/ფილტრების რამდენიმე
ტექსტიც მხოლოდ ქართულად იყო დაწერილი.

ახლა მენიუ, ფილტრი, კატალოგის სათაური, პროდუქტის კატეგორია და breadcrumb ერთსა და იმავე
KA/EN/RU თარგმანს იყენებს. თქვენს მიმდინარე კატალოგში ნანახი სახელები მხარდაჭერილია:

ზოგადი პროდუქტის ზუსტი სახელები („კაბა“, „კოსტუმი“, „პერანგი“) ერთობით ითარგმნება:
Dress / Suit / Shirt. ინდივიდუალური პროდუქტის/კოლექციის სახელი და აღწერა ავტომატური
მანქანური თარგმნით არ იცვლება. უცნობი სახელი ორიგინალად რჩება.

მზა ლექსიკონი მუშაობს merge/deploy-ის შემდეგ **ბაზის განახლების გარეშეც**.
არსებული კატეგორიის slug, პროდუქტის ბმული, ფასი, მარაგი და ძირითადი ჩანაწერები უცვლელია.
ენის შეცვლა მომხმარებლის ბრაუზერში ხდება და კატეგორიის სახელს ბაზაში არ გადაწერს.

## ინდივიდუალური თარგმანების შენახვა

ადმინის კატეგორიების რედაქტორში არის ქართული, ინგლისური და რუსული სახელების არჩევითი ველები.
მათი შესანახად ერთხელ უნდა შესრულდეს [prisma/categories.sql](../prisma/categories.sql)
Neon-ის SQL Editor-ში ან `npm run db:categories`-ით, სწორი ბაზის გარემოში.
ჯერ განიხილეთ SQL და შეამოწმეთ ცალკე Neon test branch-ზე.

SQL მხოლოდ CategoryTranslation ცხრილსა და Category-ზე კავშირს ამატებს; არსებულ ჩანაწერებს
არ ცვლის და არაფერს თესავს. ის build/deploy-ის დროს ავტომატურად არ ეშვება.
`db push`, reset ან seed რეალურ ბაზაზე არ გამოიყენოთ. SQL ერთჯერადია;
განმეორებითი შესრულების შეცდომა მთელ ტრანზაქციას გააუქმებს.

ცხრილის დამატებამდე ველები გათიშულია და ძირითადი კატეგორიების შექმნა/რედაქტირება
ჩვეულებრივ მუშაობს. ბაზის განახლების შემდეგ გვერდის refresh ველებს გაააქტიურებს.

მითითებული თარგმანი ლექსიკონზე უპირატესია. ველის გასუფთავება მხოლოდ იმ ენის
თარგმანს შლის და აბრუნებს მზა თარგმანს/ორიგინალს; სხვა ენებს არ ეხება.
კატეგორიის დამალვა თარგმანებს ინახავს, ხოლო წაშლა მის თარგმანებსაც შლის.

## ვიზუალური განახლება

ბორდოს მსუბუქი აქცენტები დაემატა header-ის ხაზს, PREMIUM წარწერას, აქტიურ მენიუს,
ფასებს, რჩეულებს, კალათის მრიცხველს, ფილტრსა და ძირითად ღილაკებს.
ფოტოები და არსებული ოთხი/სამი/ორი სვეტის განლაგება შენარჩუნებულია.
მუქი თემა იყენებს უფრო ნათელ ვარდისფერ აქცენტს, ტექსტის კონტრასტის შესანარჩუნებლად.
